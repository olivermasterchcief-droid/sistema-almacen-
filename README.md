# 📦 Sistema Integral de Control de Almacén

Sistema de escritorio desarrollado en Python para la trazabilidad 
y gestión de materiales en almacén industrial.

## 🚀 Características

- Registro de paquetes con foto, ubicación y responsable
- Búsqueda en tiempo real por caja, proyecto o ubicación
- Control de estado (Surtida / Pendiente)
- KPIs en tiempo real (total y porcentaje surtido)
- Exportación a CSV
- Visor de imágenes integrado
- Base de datos local con SQLite

## 🛠️ Tecnologías

- Python 3
- CustomTkinter (interfaz moderna dark mode)
- SQLite3 (base de datos local)
- Pillow (manejo de imágenes)

## 💡 Problema que resuelve

Elimina el registro manual en papel o Excel de materiales en almacén 
industrial, reduciendo errores y tiempo de búsqueda de paquetes.
